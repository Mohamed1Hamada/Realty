# Realty Office — ورقة المميزات (للبيع)

> نسخة أولية (MVP) جاهزة للتشغيل الفعلي — مش نموذج تجريبي.

---

## لمن النظام ده؟

لأي مكتب عقارات أو وسيط عقاري بيدير:
- عدد من الوحدات (بيع وإيجار)
- فريق من الموظفين أو الوسطاء
- عقود وعمولات ومصروفات شهرية

---

## المميزات الأساسية

### 🏢 إدارة العقارات
- تسجيل كامل لكل وحدة: النوع، المساحة، الغرف، الدور، التشطيب، السعر، الموقع، بيانات المالك.
- كود مرجعي تلقائي لكل عقار يسهل التواصل بيه.
- تصنيف فوري: متاح / محجوز / مُباع / مُؤجر / موقوف.
- بحث وتصفية سريعة حسب المنطقة والسعر والنوع.
- تصدير القائمة لملف Excel (CSV) في ضغطة.

### 👥 قاعدة بيانات العملاء
- تفصيل بين المشتري والمالك.
- معرفة مصدر العميل (فيسبوك، OLX، ترشيح، زيارة المكتب) — عشان تعرف أنهي تسويق بيشتغل.
- ميزانية العميل وحالته (محتمل / نشط / تم التعامل / خسران).

### 📞 نظام المتابعات
- كل عميل ليه مراحل واضحة من أول مكالمة لحد إتمام الصفقة.
- تنبيه فوري بالمتابعات المتأخرة واللي مستحقة النهاردة.
- زر واحد لتحريك العميل للمرحلة الجاية.

### 📝 العقود والعمولات
- تسجيل عقود البيع والإيجار مع تواريخ البداية والنهاية.
- **حساب العمولة تلقائيًا** من قيمة العقد ونسبة الموظف.
- متابعة المسدد والمتبقي من العمولة.
- عند إتمام العقد: العقار يتحوّل تلقائيًا لـ "مُباع" أو "مُؤجر".

### 💰 حسابات المكتب
- دفتر إيرادات ومصروفات ببنود جاهزة (إيجار المكتب، مرتبات، تسويق، كهرباء…).
- ملخص الشهر الحالي وكل الفترة + صافي الربح.
- العمولة المسددة بتتسجّل تلقائيًا من العقد — من غير إدخال مرتين.

### 📊 لوحة تحكم
- مؤشرات لحظية: عدد العقارات، المتاحة، المُباعة، العملاء، العقود، العمولات، الصافي.
- رسم بياني للإيرادات مقابل المصروفات لآخر ٦ شهور.
- توزيع العقارات حسب النوع + ترتيب الموظفين بالعمولات.

### 👮 الصلاحيات والأمان
- حساب مدير وحسابات موظفين.
- الموظف **لا يستطيع** رؤية بيانات غير عملائه وعقاراته (حماية على مستوى قاعدة البيانات).
- البيانات على سيرفرات Supabase مع نسخ احتياطي يومي.

### 🌐 عربي / English
- واجهة ثنائية اللغة بالكامل مع دعم كامل للاتجاه من اليمين لليسار (RTL).
- تبديل اللغة بزر واحد.

## ما يميّز النسخة دي

| الميزة | الفائدة للمكتب |
|---|---|
| وضع عرض تجريبي مدمج | تقدر تجرّب النظام ببيانات واقعية قبل ما تربطه |
| ربط Supabase في ٢٠ دقيقة | مفيش سيرفر تشتريه أو تصيّنه |
| صلاحيات على مستوى قاعدة البيانات | أمان حقيقي مش مجرد إخفاء أزرار |
| تصدير CSV لكل الجداول | بياناتك ملكك، تقدر تخرجها في أي وقت |
| ثنائي اللغة | مناسب لو المكتب بيتعامل مع أجانب |
| هوية قابلة للتخصيص | اسم المكتب ولونه من ملف واحد |

---

## ما لا تشمله النسخة الأولى (يُضاف في مرحلة تانية)

- رفع صور العقارات مباشرة من الموبايل (حاليًا بروابط صور — التخزين جاهز في Supabase).
- جدول أقساط العملاء وتنبيهات التأخير.
- طباعة العقود PDF بشعار المكتب.
- إشعارات واتساب/بريد تلقائية.
- موقع عرض عام للعملاء.

---

## المتطلبات التقنية للتشغيل

- جهاز كمبيوتر + متصفح حديث (Chrome / Edge / Safari).
- حساب مجاني على [Supabase](https://supabase.com) (الخطة المجانية تكفي لمكتب واحد).
- استضافة مجانية على Vercel أو Netlify.

**التكلفة الشهرية للتشغيل: صفر جنيه** على الخطة المجانية لحد حجم معقول من البيانات.

## نموذج اقتراح السعر (للاسترشاد)

| البند | الوصف |
|---|---|
| الترخيص الأساسي | تركيب النظام + ربط Supabase + تدريب ساعة |
| اشتراك الدعم الشهري | تحديثات + نسخ احتياطي + دعم فني |
| تخصيص إضافي | تعديل الألوان/الشعار/الحقول حسب طلب المكتب |
| تطوير مرحلة تانية | أقساط، PDF، إشعارات… (بسعر منفصل) |

> حدّد أسعارك حسب سوقك المحلي. القاعدة: قيمة النظام = وقت الموظفين اللي بيوفّره + الصفقات اللي مش هتضيع بسبب نسيان متابعة.

## خطوات التسليم للعميل

1. وقّع الاتفاق واتفق على اسم المكتب ولون الهوية.
2. نفّذ `docs/SETUP_SUPABASE_AR.md` بالكامل.
3. ادخل بيانات المكتب الحقيقية (العقارات والعملاء) أو صدّرها من ملف Excel.
4. أنشئ حساب لكل موظف ووزّع الصلاحيات.
5. درّب الفريق ساعة على: إضافة عقار، تسجيل متابعة، إنشاء عقد.
6. سلّم العميل: رابط النظام + بيانات الدخول + نسخة من `schema.sql` (ملكية بياناته).
